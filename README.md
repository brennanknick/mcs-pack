# MCS resource pack

The resource pack for the MCS Minecraft server: club crests, kits, goals and bow skins.

It lives here rather than on the game server because the server hands it out over plain
HTTP from a bare IP on a non-standard port, and that combination is blocked by some
antivirus and school or office web filters — which locked those players out entirely,
since the pack is required. GitHub serves it over HTTPS from a domain those filters
already trust.

`pack.zip` is generated by the SoccerGame plugin (`/referee pack build`) and copied here
whenever it changes. The server is told its SHA-1 so the client can cache it.
